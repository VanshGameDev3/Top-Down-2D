# Shadow’s Blade

A fast-paced 2D action game built using Unity and C#, focused on intense combat and skill-based gameplay.


## About the Game

Shadow’s Blade is a top-down horde survival game where the player controls a ninja equipped with a unique 360-degree throwable katana.
The game challenges players to survive against waves of enemies using precise movement, quick reflexes, and strategic positioning.


## Core Features

* 360-degree throwable katana mechanic (mouse-based aiming)
* Smooth and responsive player movement
* Enemy AI with dynamic horde spawning
* Real-time combat system with collision detection
* Multiple biome-based levels
* JSON-based save and load system
* Audio system for immersive gameplay


## Tech Stack

* Engine: Unity
* Language: C#
* Data Handling: JSON (Save/Load System)
* Platform: PC (Windows)


## Gameplay Overview

* Use keyboard (WASD) for movement
* Aim using mouse (360-degree direction)
* Throw katana to defeat enemies
* Survive as long as possible against enemy waves
